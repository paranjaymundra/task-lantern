# Task Lantern — a clear view of long tasks

## Product and audience
A local HTML progress workspace for people running long tasks in Claude Code or Codex. It collects only threads enabled for Task Lantern across projects. The agent publishes snapshots; this is not automatic process monitoring.

## Direction
Prioritize first-time understanding. One headline and one idea per scene. Use a full-page fade through warm paper before changing the camera framing or content. Preserve readable holds. No numbered callouts, focus outlines, moving zooms, progress graphics, or word-by-word entrances. Keep the narrator and a quiet original music bed.
