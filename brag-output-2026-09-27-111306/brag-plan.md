# Task Lantern — from uncertainty to a clear view

## Direction
Start with the problem: a busy coding agent may be progressing, blocked, or waiting for the user. Introduce the workspace as the answer, then explain thread selection, questions, deeper details, and agent-published updates. Reserve the Task Lantern name, logo, and spoken introduction for the closing reveal.

Use thin, restrained highlights anchored to actual DOM elements in the recording. Each highlight follows the narration: current step, blocker, required answer, selected thread, question, waiting action, reply location, expandable details, current plan step, publication metadata, and local file status. No numbered callout strips or separate word animations. Preserve whole-page fades.

Demo labels and the in-app brand are hidden only in the isolated recording profile. The interactive demo shipped with the repository is unchanged. Footage uses fictional task data and scripted interaction.
